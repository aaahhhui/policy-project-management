# 适创科技企业档案初稿（首期开发样本）

> 版本：v0.1  
> 生成日期：2026-07-23  
> 用途：政策评估系统首期开发、页面联调和评估链路测试  
> 数据边界：仅使用公司官网、政府公开文件、公开专利记录及可追溯的公开二手资料；未公开或无法交叉验证的信息不补猜

## 1. 结论

首期可按“一份企业共享档案 + 北京、苏州、深圳三个经营主体”初始化开发数据。三地完整名称和办公地址已由公司官网确认；北京、苏州的部分工商或资质字段有政府公示佐证，深圳以公司名义对外展示并持有公开专利，但其法人属性仍需用营业执照或国家企业信用信息公示系统终审。

## 2. 数据使用规则

| 可信等级 | 判断标准 | 开发使用方式 |
|---|---|---|
| A：已公开核验 | 公司官网、政府网站或公开专利记录可直接确认 | 可进入开发初始化数据 |
| B：候选待确认 | 可追溯二手公开资料，或只有单一公开来源 | 可用于页面展示和规则联调，标记“待确认” |
| C：待补充 | 未找到可靠公开信息，或属于公司内部资料 | 保持为空，不生成虚构值 |

注意：

- 公司官网“联系我们”页面提供的是办公地址，不直接等同于工商注册地址。
- 资质公示只证明企业曾进入相应名单，不自动代表证书目前仍在有效期内。
- 专利仅选取代表性公开记录，不表示完整知识产权数量。
- 当前资料不包含任何保密财务数据、研发投入明细或个人敏感信息。

## 5. 首期开发导入建议

### P0：立即用于开发

1. 企业共享档案的行业、业务方向、技术能力、产品、统一电话和邮箱。
2. 三个经营主体的完整名称、注册地区和官网办公地址。
3. 北京统一社会信用代码。
4. 三个主体各一条代表性专利样本。
5. 北京、苏州各一条资质候选，用于测试“有效期未明确”和“待确认”展示。
6. 所有来源 URL、来源类型、抓取/录入日期和可信等级。

### P0：正式启用前必须确认

1. 深圳主体究竟是独立法人还是非独立分公司。
2. 苏州统一社会信用代码。
3. 三个主体的营业执照注册地址、精确成立日期、法定代表人、注册资本和经营范围。
4. 北京、苏州现行有效的高新技术企业证书及有效期。
5. 深圳主体可用于申报的资质证书。

### P1：由内部非保密资料补充

1. 各主体员工人数、研发人员人数及统计日期。
2. 各主体近三年研发投入、营业收入及研发投入比例；如只允许提供比例，则不录入金额。
3. 软件著作权、商标和完整专利清单。
4. 已验收科技项目、政府资金项目及申报结果。
5. 各主体之间的股权或控制关系，以及政策申报时可否合并口径。

### P2：后续完善

1. 客户案例、行业覆盖、奖项和人才项目。
2. 研发场地、研发设备和产学研合作情况。
3. 资质证照到期提醒和自动公开信息更新。

## 6. 开发验收样例

| 场景 | 预期结果 |
|---|---|
| 北京市海淀区政策要求申报主体在海淀注册 | 北京主体进入下一步评估；苏州、深圳命中地区不匹配 |

| 深圳市政策要求独立法人和统一社会信用代码 | 深圳主体显示“法人属性和统一社会信用代码待补充”，结论为无法判断 |
| 政策要求拥有相关发明专利 | 系统分别引用三个主体的专利样本，但不得把北京专利继承给苏州或深圳 |
| 负责人执行“更新公开信息” | 只更新当前经营主体的公开字段，不覆盖内部研发投入或人员数据 |
